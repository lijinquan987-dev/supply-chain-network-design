# 数据字典（Data Dictionary）

> 本仓全部使用**公开数据**（行政区经纬度、公开路网距离/耗时），字段口径与 Excel + OpenSolver 模型完全一致。

## 1. 点位数据（`data/raw/cities.csv`）

| 字段 | 类型 | 说明 | 示例 |
|---|---|---|---|
| 位置ID | str | 需求点 XQ001-XQ337 / 候选仓 HC01-HC15 / 总仓 ZC001 | XQ001 |
| 位置类型 | str | 需求点 / 候选仓 / 总仓 | 需求点 |
| 城市名称 | str | 地级行政区名称 | 上海市 |
| 经度 | float | 高德 GCJ-02 坐标系 | 121.47367 |
| 纬度 | float | 高德 GCJ-02 坐标系 | 31.23053 |

- 337 个需求点（地级行政区）+ 15 个候选仓（基于城市群与交通骨架预筛）+ 1 个总仓（ZC001 深圳市）

## 2. 需求点（`data/processed/demand.csv`，337 行）

| 字段 | 说明 |
|---|---|
| 需求点ID / 城市名称 | 唯一标识 |
| 日均单量_单 | 日均订单量（研究假设口径） |
| 订单均重_kg | 单均重量，模型统一按 0.35 kg/单 |
| 日均货量_kg | 参考货量列（补货成本计算不直接用此列，按 单量×0.35） |
| 目标时效D+1/D+2/D+3/D+4_h | 24/48/72/96 小时分级时效目标 |
| 目标时效等级 | 4=D+1，3=D+2，2=D+3，1=D+4 |

## 3. 候选仓（`data/processed/candidates.csv`，15 行）

| 字段 | 说明 |
|---|---|
| 候选仓ID / 城市名称 | HC01-HC15 |
| 模型指派 | 当前方案是否选中（0/1，9 仓方案参考） |
| 单均固有成本分摊_元每单 | 仓储成本参数（0.25–0.30） |
| 单均操作费_元每单 | 仓储操作成本参数（1.8） |
| 总仓ID | 总仓 ZC001 |

## 4. 补货成本（`data/processed/replenish.csv`，15 行）

| 字段 | 说明 |
|---|---|
| 候选仓ID / 候选仓城市 | 分仓 |
| 总仓ID / 总仓城市 | 总仓 ZC001 深圳市 |
| 补货运距_km | 总仓→分仓干线距离 |
| 补货运距单价_元每kg | 按距离区间定价（0.8–2.2 元/kg） |
| 运距耗时_h | 干线运输耗时 |

## 5. 配送成本时效矩阵（`data/processed/distance_cost.csv`，5055 行 = 337×15）

| 字段 | 说明 |
|---|---|

| 需求点ID / 候选仓ID | 组合键 |

| 快递运距时效SLA_h | 该组合的配送时效 |
| 城市目标时效半径_h | 需求城市的目标时效 |
| SLA与目标匹配 | 0/1（SLA ≤ 目标半径） |

## 7. 成本口径（与 Excel OpenSolver 模型一致）

| 成本 | 公式 | 说明 |
|---|---|---|
| 仓储 | 单量 ×（单均固有分摊 + 单均操作费） | 按候选仓参数 |
| 补货 | 单量 × 0.35 kg/单 × 补货运距单价（元/kg） | 按距离区间定价 |
| 配送 | 单量 × 单均快递成本 | 按城间运距 |

## 8. 数据来源（Data Sources）

- 行政区划经纬度：高德开放平台地理编码（公开接口）
- 城间距离/耗时：高德开放平台距离测量 API（公开接口，需个人 Key，**Key 不入库**）
- 单量/成本参数：研究假设口径（行业公开水平），不涉及真实企业数据
